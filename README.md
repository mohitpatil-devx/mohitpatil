## Featured Project

### [Employee AI Assistant](https://github.com/snake0507/employee-ai-assistant)

An LLM-powered assistant that answers employee-data questions and retrieves company-policy information.

- Uses **Gemini** with tool calling to select relevant employee-data functions.
- Connects a **FastAPI** backend to **PostgreSQL** for structured employee data.
- Uses **ChromaDB** and retrieval-augmented generation (RAG) for company-policy questions.
- Includes an **Angular + TypeScript** frontend.
- Can combine database results and policy context when a question needs both.

**Tech:** Python, FastAPI, Gemini, PostgreSQL, ChromaDB, Angular, TypeScript

> This is a learning project using demonstration data, not a production HR system.
